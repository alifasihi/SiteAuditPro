# 🔍 SiteAuditPro

ابزار خط فرمان پایتون برای **بررسی سریع سئو و سلامت فنی وب‌سایت**. SiteAuditPro یک صفحه را تحلیل می‌کند و خروجی را هم به‌صورت **JSON** (برای پردازش ماشینی) و هم **گزارش HTML فارسی** (برای مشاهده و ارائه به کارفرما) ذخیره می‌کند.

---

## ✨ امکانات

- **اطلاعات پایه صفحه:** Title، Meta Description، Canonical، زبان صفحه (`lang`) و Viewport
- **بررسی سئو با وضعیت «خوب / نیاز به بررسی»:**
  - طول Title (بازه مناسب: ۳۰ تا ۶۰ کاراکتر)
  - طول Description (بازه مناسب: ۷۰ تا ۱۶۰ کاراکتر)
  - تعداد تگ H1 (مناسب: دقیقاً یک عدد)
- **استخراج ساختار تیترها:** H1 ،H2 و H3
- **Open Graph:** استخراج تمام تگ‌های `og:*`
- **تحلیل لینک‌ها:** جداسازی لینک‌های داخلی و خارجی
- **تشخیص لینک خراب:** بررسی وضعیت حداکثر ۳۰ لینک داخلی اول (با `HEAD` و در صورت نیاز `GET`)
- **تحلیل تصاویر:** تعداد تصاویر و تصاویر فاقد `alt`
- **بررسی `robots.txt` و `sitemap.xml`**
- **مدیریت خطا:** Timeout، قطع اتصال و خطاهای HTTP بدون از کار افتادن برنامه
- **تأخیر بین درخواست‌ها** برای جلوگیری از فشار به سرور هدف

## 📦 پیش‌نیازها

- Python 3.8 یا بالاتر
- کتابخانه‌ها:
  - `requests`
  - `beautifulsoup4`

## 📤 خروجی‌ها

بعد از اجرا، دو فایل در پوشه جاری ساخته می‌شود:

| فایل | توضیح |
|------|-------|
| `website_report.json` | گزارش کامل و ساختاریافته (مناسب برای اتصال به سایر ابزارها) |
| `website_report.html` | گزارش خوانا و راست‌به‌چپ برای مشاهده در مرورگر |

### نمونه خروجی در ترمینال


## ⚙️ تنظیمات

در بالای فایل می‌توانید این مقادیر را تغییر دهید:

| متغیر | کاربرد | پیش‌فرض |
|-------|--------|---------|
| `HEADERS` | User-Agent درخواست‌ها | مرورگر Chrome |
| `TIMEOUT` | حداکثر زمان انتظار برای پاسخ (ثانیه) | `10` |
| `internal_links[:30]` | تعداد لینک‌های داخلی برای بررسی خرابی | `30` |
| `time.sleep(0.2)` | فاصله بین بررسی لینک‌ها (ثانیه) | `0.2` |

---

## ⚠️ محدودیت‌ها

- فقط **یک صفحه** (آدرس داده‌شده) تحلیل می‌شود، نه کل سایت.
- سایت‌هایی که محتوا را با **جاوااسکریپت** (SPA) رندر می‌کنند ممکن است کامل تحلیل نشوند، چون ابزار HTML خام را می‌خواند.
- بررسی لینک‌های خراب به ۳۰ لینک داخلی اول محدود است.
- نتایج سئو یک **ارزیابی اولیه** است و جایگزین ابزارهای تخصصی نیست.
